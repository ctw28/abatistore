ABATI STORE — HALAMAN DETAIL PRODUK
Isi ZIP:
- detail-produk.blade.php: template satu halaman lengkap (header, detail produk, ongkir, tab, cara belanja, produk terkait, footer, sticky CTA mobile, JS interaksi)
- 09-product-detail.css: stylesheet khusus halaman detail

Pemasangan:
1. Tempatkan Blade pada resources/views sesuai struktur proyek dan sambungkan route produk.
2. Tempatkan CSS di public/css/newweb/09-product-detail.css.
3. Sesuaikan data produk dengan data Laravel/database.
4. Periksa nama logo dan nomor WhatsApp.
5. Tabel kecamatan/tarif, harga, foto real pict, video, panduan ukuran, link Shopee dan produk terkait masih contoh/placeholder; ganti sebelum produksi.
6. Header/footer disertakan sebagai contoh lengkap. Jika proyek memakai Blade partial, gunakan partial yang sudah ada agar tidak duplikat.
7. CSS menggunakan prefix pd- agar tidak sengaja menimpa class homepage. Template mengikuti struktur header yang terlihat pada template homepage, tetapi belum diuji terhadap seluruh CSS dan route aktif situs.
